# Student ID Card Generator

A browser-based tool to generate student ID cards from an Excel sheet and photo ZIP file.

## Features
- Upload Excel sheet with student data
- Upload ZIP file containing student photos
- Automatically generates ID cards for all students
- Download each ID card as a PNG image

## Excel Format
The Excel sheet should have these columns:
| Name | Address | DOB | Phone no | Aadhar | Photo Filename |

## How to Use
1. Open the website
2. Upload your Excel file (.xlsx)
3. Upload your photos as a ZIP file
4. Click Generate ID Cards
5. Download any card as PNG

## Built With
- HTML, CSS, Vanilla JavaScript
- SheetJS — Excel parsing
- JSZip — ZIP extraction
- html2canvas — PNG download
